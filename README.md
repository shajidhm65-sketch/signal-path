# SignalPath 📡

**SignalPath** is a live GPS positioning and interactive radio signal analyzer prototype. It allows users to assess cellular and internet signal quality (high/low levels) across specific regions, starting with Chennai.

> ⚠️ *Note: This is currently a functional web prototype. Future iterations will scale into a dedicated mobile application.*

---

## ✨ Key Features

* **Live GPS Tracking**: Automatically acquires and locks onto your current device position with accuracy radius mapping.
* **Interactive Regional Scanner**: Click anywhere on the map to inspect local signal strengths and generate simulated tower data around that specific spot.
* **Signal Strength Filtering**: Quickly filter map nodes by **Strong**, **Usable**, or **Weak** signal profiles.
* **Detailed Telemetry**: View dBm signal power metrics, network technology types (5G NSA, 4G LTE, 3G), and distance calculations from your inspection point.

---

## 🛠️ Tech Stack

* **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+)
* **Mapping Library**: [Leaflet.js](https://leafletjs.com/) (v1.9.4)
* **Map Tiles**: Esri World Street Map
